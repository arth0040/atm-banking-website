# Arth calculator

Arth calculator is a friendly calculator and Python learning companion supporting addition, subtraction, division, floor division, multiplication, exponentiation, and modulus.

## Contents

- The complete runnable project is packaged in **arth-calculator.zip**.
- The readable source files are mirrored alongside the archive for easy browsing.
- The archive includes the app entry point, responsive UI, safe validation, division-by-zero protection, and Python lesson content.

## Run locally

Download and extract **arth-calculator.zip**, install its dependencies, and run the Vite development server from the extracted project folder.
